# Dinosaur Catches Rabbits

[中文](README.zh.md)

A little browser game: drag the dinosaur to catch 6 rabbits, and once they're all caught, everyone watches the fireworks together 🎆

Play online: <https://chenqianyu.fun/>

![Title screen](screenshots/preview-title.png)

## How to play

- Drag on screen / move the mouse / use the arrow keys (or WASD) to control the dinosaur
- Catch all 6 rabbits to win — no losing, just happy fun

## Running

Just open `index.html` directly in a browser — no internet connection or installation needed.
